# Problemática

La pizzería actualmente no cuenta con un sistema digital que permita 
a sus clientes realizar pedidos en línea de manera eficiente. 
Los pedidos se gestionan de forma manual, lo que genera errores, 
tiempos de espera largos y una experiencia poco satisfactoria 
para el cliente.

## Solución Propuesta

Desarrollar una aplicación web para la pizzería que permita a los 
clientes explorar el menú, personalizar sus pedidos y realizar 
pagos en línea, optimizando el proceso de venta y mejorando 
la experiencia del usuario.

## Funcionalidades Principales

- Catálogo de pizzas con tamaños (chica, mediana, grande)
- Selección de sabores y personalización de ingredientes
- Combos y promociones especiales
- Combos familiares
- Descuentos y ofertas del día
- Pago con tarjeta y efectivo
- Identidad de marca de la pizzería
